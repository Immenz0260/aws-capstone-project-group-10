# AWS First Capstone Project

## Project Overview
This project is part of our AWS Cloud Computing Capstone Project. The goal is to design, deploy, and manage cloud-based resources using Amazon Web Services (AWS) while applying best practices for collaboration, security, and documentation.
The project focuses on setting up and managing core AWS services, implementing access control through IAM, and collaborating effectively using GitHub and Trello.

## Project Objectives
- Create and manage AWS cloud resources.
- Implement secure user access using IAM.
- Deploy and manage EC2 instances.
- Store and manage data using Amazon S3.
- Collaborate effectively using GitHub.
- Track project tasks and progress using Trello.
- Document project activities and outcomes.

## Setup Steps

### 1. AWS Account Setup
- Create or access the AWS account.
- Configure IAM users for team members.
- Assign appropriate permissions to IAM users.

### 2. EC2 Instance Setup
- Launch an Amazon EC2 instance.
- Configure security groups.
- Connect to the instance using SSH.

### 3. S3 Bucket Setup
- Create an S3 bucket.
- Configure bucket permissions.
- Upload and manage project files.

### 4. GitHub Repository Setup
- Create a GitHub repository.
- Add all team members as collaborators.
- Clone the repository locally.
- Create branches for development work.
- Commit and push changes regularly.

### 5. Project Management
- Create a Trello board.
- Assign tasks to team members.
- Track project progress and milestones.
